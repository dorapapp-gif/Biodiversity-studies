2.3 Geometric

It is very uneven. Large numbers of individuals are needed. Only used for example for soil microbes to describe their distribution.

Microbes live in a very competitive system where the first species have a very unequal chance to occupy spaces. There is a real “first comes first serves” idea in communities creating a very strong hierarchy in the system.

A sequential broken stick.

Random distribution.

rcommunity(
  # One community - in this model the number of species is what defined and what % of the resources the first species will get
  1,
  # Number of trees
  size = 1E6,#10000 original number
  # Number of species
  species_number = 300,
  # Distribution
  distribution = "geom", #geometric distribution
  prob_geom = 0.1
) %>% 
  # Whittaker plot
  autoplot()

2.7 Zero-sum multinomial distribution

A hard way to simulate a distribution that fits neutral model.

BCI parameters \(\theta\) and \(m\) are estimated following Etienne (2005) with the untb package.

Here is the code to run it with the BCA data. Already loaded is a file. The data is too large for R to compute it. R does not have enough integer space to compute it.

# BCI data
library("vegan")
data(BCI)
BCI_50ha <- colSums(BCI)

# library("untb")

  # Use the saved result if available to save
  # computation resources
  load("data/BCI_logkda.RData")
} else {
  BCI_50ha %>% 
  # name conflict with dplyr::count()
  untb::count() %>%

3.3 Accumulation curve

Compute the expected accumulation curve of BCI up to twice the sampling effort, with its confidence interval.

#Species accumulation curve - depends a lot on a sampling size - exact sampling effort. If it is small adding a few species can have a big effect. You need to have large samples. It gets relatively flat at 10000 samples (when it starts to be relatively flat)

#in respect to a certain number of trees
#but what about area?

# Number of trees in BCI
BCI_n <- abd_sum(BCI_all, as_numeric = TRUE) #counting the number of trees
# Asymptotic richness
BCI_richness <- div_richness(BCI_all, as_numeric = TRUE) #how many species are there in total
BCI_all %>% 
  accum_hill(
    levels = seq(from = 1, to = 2 * BCI_n, by = 10), #up to 2x the size of sample, extrapolation is valable (according to Caho 2014) by= calculation of every 10
    # Run simulations to estimate uncertainty.
    # Start with 10 simulations, run 100 later
    n_simulations = 10, #multinomial simulation
  ) %>% 
  autoplot() +
  geom_vline(xintercept = BCI_n, linetype = 2) + #creating a vetical line on the plot (here we set it to the sample size - after it is extrapolated)
  geom_hline(yintercept = BCI_richness, linetype = 1)
#only ten times simulated - in order to get a better confidence line you would need 1000 times
#confidence interval gets narrower because there are less to miss because the model because the model is in the rare species area

The red curve is the smoothed Preston plot of BCI, i.e. the probability density for a species to contain a given number of individuals. The black curve is the probability for an individual to belong to a species that contains that number of individuals.
